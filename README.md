# Financial Risk Analysis with Python

## Project Overview
This project analyzes Morgan Stanley customer transaction data to identify financial behavior patterns, customer segments, and risk indicators.

## Objectives
- Data Cleaning and Preprocessing
- Transaction Analysis
- Customer Segmentation
- Risk Detection
- Hypothesis Testing
- Data Visualization

## Dataset
Morgan Stanley Financial Transaction Data

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Insights
- Analyzed customer transaction behavior
- Identified high-risk accounts
- Segmented customers by activity level
- Performed anomaly detection
- Conducted statistical hypothesis testing
